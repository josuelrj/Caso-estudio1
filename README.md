SG Business Hub - Grupo 7

Descripción del proyecto

SG Business Hub es una aplicación web académica orientada a la gestión empresarial.

El sistema busca facilitar la administración de clientes, proyectos, solicitudes, cotizaciones, inventario, producción y usuarios.

Tecnologías utilizadas

* Python
* Flask
* SQLite
* HTML
* CSS
* Git y GitHub

Funcionalidades iniciales

* Inicio de sesión.
* Gestión de usuarios y roles.
* Tablero de control.
* Gestión de clientes.
* Gestión de proyectos.
* Gestión de inventario.
* Registro de actividades.
